# EDA Operations using Pandas and NumPy

This project demonstrates the Exploratory Data Analysis (EDA) operations listed in the professor-provided reference document.

## Operations covered

- Loading CSV data
- `head()`, `tail()`, `shape`, `columns`, `dtypes`, `info()`
- `describe()`
- Mean, median, mode, variance, standard deviation
- Minimum, maximum and count
- Unique values, number of unique values and value frequencies
- Missing-value detection, count and percentage
- Dropping and filling missing values
- Duplicate detection, counting and removal
- Column/row selection
- Conditional filtering
- Sorting
- Renaming columns
- Creating and deleting columns
- Grouping and group averages
- Concatenating datasets
- Merging datasets
- A small NumPy example

## How to run

```bash
pip install -r requirements.txt
python eda_operations.py
```

The script uses the included `data.csv` as a small demonstration dataset.

## Reference

The commands and operation list are based on the professor-provided `EDA Operations.docx`.
